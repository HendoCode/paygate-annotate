Paygate Annotate

Styles

Each style becomes an entry in the right-click Paygate menu. CSS is a list of declarations applied to the link (e.g. color: red; text-decoration: line-through; opacity: .6); they're applied with !important. Before/After text is shown around the link text. Card CSS is applied to the whole article card on sites where one can be identified (currently Google News), e.g. opacity: .4.

Rules

First match wins, top to bottom. Domain matches the domain and all its subdomains (theatlantic.com covers www.theatlantic.com). Regex is tested, case-insensitively, against the full destination URL (for Google News links only the publisher host is known, as https://host/).
